# Tic Tac Toe

A clean and minimal **Tic Tac Toe** game built with HTML, CSS, and JavaScript.

Designed with a warm, simple interface and focused on a smooth two-player experience.

## Features

- Two-player gameplay
- X and O turns
- Automatic winner detection
- Draw detection
- Score tracking
- New game without resetting the score
- Reset score option
- Responsive design
- Clean, minimal, non-neon UI

## Built With

- **HTML5** — Structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Game logic and interactions

## How to Play

1. Player X starts the game.
2. Players take turns placing their symbol.
3. Get three symbols in a row horizontally, vertically, or diagonally to win.
4. If all nine boxes are filled without a winner, the game ends in a draw.
5. **New Game** starts another round while keeping the score.
6. **Reset Score** starts fresh with both scores set to zero.

## Run Locally

No installation or dependencies are required.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/tic-tac-toe.git
```

Open the project folder and launch `index.html` in your browser.
